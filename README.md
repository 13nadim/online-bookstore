# Online Bookstore

## Overview

First-year university module submission for **Web Design and Development**. An online bookstore built with **HTML, CSS, PHP, and MySQL**.
Designed to mimic the operation of a **payment gateway** in an e-commerce website. Users can browse books, view descriptions and enter credit card details to complete a purchase.

## Installation / Setup

1. Clone the repository.
2. Place the project in your local server folder.
3. Start Apache and MySQL.
4. Set up the database.
5. Update database connection (if necessary).
6. Open your browser and navigate to `http://localhost/web/index.php` to preview the site.

## Notes

This project requires a local PHP/MySQL environment to run (e.g., **XAMPP**).  
The database credentials are currently **hardcoded** in the PHP files for simplicity, which is acceptable for this first-year module project.  
Future improvements could include using a **separate configuration file** or **environment variables** to store database credentials securely, following professional best practices.
